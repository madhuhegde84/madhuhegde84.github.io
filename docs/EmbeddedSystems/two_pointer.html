Two Pointer Technique

The Two Pointer technique is a common algorithmic pattern used to solve problems involving arrays or linked lists with high efficiency (usually O(n) time complexity and O(1) space complexity).

1. Basics of the Technique

As the name suggests, we use two pointers (usually indices) to traverse a data structure. There are two main variations:

  • Opposite Directions: One pointer starts at the beginning (left) and another at the end (right). They move towards each other until they meet.
  • Same Direction (Fast/Slow): Both pointers start at the same end but move at different speeds or intervals.
Array: [ 1, 3, 4, 6, 8, 9 ] ^ ^ Left Right (Pointers move towards the center)

2. Why use it in Embedded Systems?

In firmware development, memory is often constrained. The Two Pointer technique is ideal because it typically works in-place, requiring no extra memory allocation, which is critical for systems with limited RAM (e.g., bare-metal or RTOS environments).

3. Simple Example: Reversing an Array

To reverse an array in-place, we swap the elements at the left and right pointers, then increment left and decrement right.

void reverseArray(int arr[], int size) {
    int left = 0;
    int right = size - 1;
    while (left < right) {
        // Swap elements
        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;
        
        left++;
        right--;
    }
}

4. LeetCode Example: Two Sum II (Sorted Array)

Problem: Given a sorted array, find two numbers such that they add up to a specific target number.

Approach: Since the array is sorted, if the sum of arr[left] + arr[right] is less than the target, we need a larger sum, so we move left forward. If the sum is greater, we move right backward. 
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* twoSum(int* numbers, int numbersSize, int target, int* returnSize) {
    int left = 0;
    int right = numbersSize - 1;
    
    while (left < right) {
        int current_sum = numbers[left] + numbers[right];
        
        if (current_sum == target) {
            int* result = (int*)malloc(2 * sizeof(int));
            result[0] = left + 1; // 1-indexed
            result[1] = right + 1;
            *returnSize = 2;
            return result;
        } else if (current_sum < target) {
            left++; 
        } else {
            right--;
        }
    }
    *returnSize = 0;
    return NULL;
}
