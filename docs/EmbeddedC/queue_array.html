Queue Implementation using Array

Focusing on the Circular Queue pattern — the standard for high-performance firmware buffering, RTOS message passing, and WLAN frame management.

1. What is a Queue?

A queue is a linear data structure following the FIFO (First-In-First-Out) principle. Elements are added at the rear and removed from the front. In firmware, a "simple" linear queue is rarely used because it requires O(n) element shifting; instead, we use a Circular Queue (Ring Buffer).

Core principle: Circular queues use modulo arithmetic to wrap the rear and front indices back to zero when they reach the array's end, achieving true O(1) operations without shifting data.

2. Core Structure

A circular queue typically tracks:

  • int *arr — Pointer to the underlying fixed-size buffer.
  • int capacity — Maximum buffer size.
  • int front — Read index (next element to be removed).
  • int rear — Write index (next position to insert).
  • Optional: int count — Tracks current number of elements (simplifies full/empty logic).

3. Key Operations (Circular Pattern)

Enqueue (Insert)

  • Check Full: If (rear + 1) % capacity == front, the buffer is full.
  • Store: arr[rear] = x;
  • Advance Rear: rear = (rear + 1) % capacity;
  • Time complexity: O(1)

Dequeue (Remove)

  • Check Empty: If front == rear, the buffer is empty.
  • Retrieve: int val = arr[front];
  • Advance Front: front = (front + 1) % capacity;
  • Time complexity: O(1)

Full vs. Empty Logic

In the common "one slot unused" implementation:

  • Empty: front == rear
  • Full: (rear + 1) % capacity == front

4. C Implementation (Circular Ring Buffer)

#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int *arr;
    int capacity;
    int front;
    int rear;
} CircularQueue;

CircularQueue* createQueue(int cap) {
    CircularQueue* q = (CircularQueue*)malloc(sizeof(CircularQueue));
    q->capacity = cap;
    q->arr = (int*)malloc(cap * sizeof(int));
    q->front = 0;
    q->rear = 0;
    return q;
}

void enqueue(CircularQueue* q, int x) {
    if ((q->rear + 1) % q->capacity == q->front) {
        printf("Queue Full (Overflow)
");
        return;
    }
    q->arr[q->rear] = x;
    q->rear = (q->rear + 1) % q->capacity;
}

int dequeue(CircularQueue* q) {
    if (q->front == q->rear) {
        printf("Queue Empty (Underflow)
");
        return -1;
    }
    int val = q->arr[q->front];
    q->front = (q->front + 1) % q->capacity;
    return val;
}

int peek(CircularQueue* q) {
    if (q->front == q->rear) return -1;
    return q->arr[q->front];
}

int isEmpty(CircularQueue* q) {
    return q->front == q->rear;
}

int isFull(CircularQueue* q) {
    return (q->rear + 1) % q->capacity == q->front;
}

7. Firmware/Embedded Use Cases

  • UART/SPI RX Buffers: UART ISR pushes to ring buffer; main task pops to process.
  • WLAN Packet Queues: Buffering TX frames between the host driver and the PHY DMA engine.
  • RTOS Message Queues: Passing data between tasks safely (with mutex/semaphore protection).
  • Sensor Data Logging: Continuous sampling where old data is overwritten or processed in batches.
  • Audio Streaming: Circular buffers for PCM data to prevent playback underflow/stutter.

8. Interview Traps and Advanced Topics

  • Power-of-2 Optimization: If capacity is 2^n, (i + 1) % capacity can be replaced with (i + 1) & (capacity - 1). This is much faster on CPUs without hardware division (like some Cortex-M0/M3).
  • Atomic Access: In a single-producer/single-consumer model, if front and rear are modified by only one side each, the queue can often be lock-free (using volatile and barriers).
  • Cache Coherency: When used with DMA, the ring buffer must be in non-cacheable memory or manually invalidated/flushed.
  • Full vs Empty ambiguity: If front == rear is used for both, you must either: (1) Leave one slot empty, (2) Use a count variable, or (3) Use a is_full flag.
  • DMA Descriptor Management: Hardware DMA controllers often use "Own" bits in a circular array of descriptors — this is effectively a hardware-managed circular queue.
