WLAN PHY Data Rate Calculation

Example: consider 64-QAM and 5/6 coding rate and short GI and 20 MHz only channel with single antenna. Step by step derive data rate as follows:

Result: Data rate = 72.2 Mbps — This is MCS 7 (64-QAM, R=5/6) for 802.11n HT20, 1 Spatial Stream, Short GI.

Step-by-Step Derivation

Step 1: Data Subcarriers

For an HT20 (20 MHz) channel in 802.11n, there are 52 data subcarriers.

\[ N_{SD} = 52 \]

Step 2: Bits per Subcarrier (BPSCS)

64-QAM encodes 6 bits per subcarrier (since \(\log_2(64) = 6\)).

\[ BPSCS = 6 \text{ bits/subcarrier} \]

Step 3: Coded Bits per OFDM Symbol (N_CBPS)

The total coded bits per OFDM symbol is the product of data subcarriers and bits per subcarrier:

\[ N_{CBPS} = N_{SD} \times BPSCS = 52 \times 6 = 312 \text{ coded bits} \]

Step 4: Information Bits per OFDM Symbol (N_DBPS)

With coding rate \(R = 5/6\), only a fraction of bits carry actual data (the rest are redundancy for error correction):

\[ N_{DBPS} = N_{CBPS} \times R = 312 \times \frac{5}{6} = 260 \text{ bits} \]

Step 5: OFDM Symbol Duration (T_SYM, Short GI)

Each OFDM symbol consists of a data interval and a Guard Interval (GI). With Short GI:

\[ T_{SYM} = 3.2\,\mu s + 0.4\,\mu s = 3.6\,\mu s \]

(Compare: Long GI uses 0.8 μs, giving TSYM = 4.0 μs.)

Step 6: Symbols per Second

The number of OFDM symbols transmitted per second:

\[ \text{Symbols/sec} = \frac{1}{T_{SYM}} = \frac{1}{3.6 \times 10^{-6}} \approx 277{,}777.78 \text{ symbols/sec} \]

Step 7: PHY Data Rate

Finally, the PHY data rate is the product of information bits per symbol and symbols per second:

\[ \text{Rate} = N_{DBPS} \times \text{Symbols/sec} = 260 \times 277{,}777.78 \approx \mathbf{72.2\,Mbps} \]

802.11ax (Wi-Fi 6) — HE20 MHz Data Rate Calculation

The following example demonstrates the data rate calculation for 802.11ax (Wi-Fi 6), which introduces several key differences over 802.11n: a much wider FFT (256 tones vs 64), higher-order modulation (up to 1024-QAM), and a longer OFDM symbol duration (12.8 μs data interval).

Result: Data rate = 143.4 Mbps — This is 802.11ax HE20, MCS 11 (1024-QAM, R=5/6), 1 Spatial Stream, Short GI (0.8 μs).

Step 1: Data Subcarriers

802.11ax HE20 uses a 256-point FFT. After subtracting pilots, guard bands and DC tone, there are 234 data subcarriers.

\[ N_{SD} = 256 - 22\,(\text{pilots/guard/DC}) = 234 \]

Step 2: Bits per Subcarrier (BPSCS)

1024-QAM — introduced in 802.11ax — encodes 10 bits per subcarrier (since \(\log_2(1024) = 10\)).

\[ BPSCS = 10 \text{ bits/subcarrier} \]

Step 3: Coded Bits per OFDM Symbol (N_CBPS)

The total coded bits per OFDM symbol:

\[ N_{CBPS} = N_{SD} \times BPSCS = 234 \times 10 = 2340 \text{ coded bits} \]

Step 4: Information Bits per OFDM Symbol (N_DBPS)

With coding rate \(R = 5/6\):

\[ N_{DBPS} = N_{CBPS} \times R = 2340 \times \frac{5}{6} = 1950 \text{ bits} \]

Step 5: OFDM Symbol Duration (T_SYM, Short GI)

802.11ax uses a much longer data interval of 12.8 μs (4× longer than 802.11n) due to its 256-point FFT. With the standard short GI of 0.8 μs:

\[ T_{SYM} = 12.8\,\mu s + 0.8\,\mu s = 13.6\,\mu s \]

Step 6: Symbols per Second

\[ \text{Symbols/sec} = \frac{1}{T_{SYM}} = \frac{1}{13.6 \times 10^{-6}} \approx 73{,}529 \text{ symbols/sec} \]

Step 7: PHY Data Rate

\[ \text{Rate} = N_{DBPS} \times \text{Symbols/sec} = 1950 \times 73{,}529 \approx \mathbf{143.4\,Mbps} \]
